# Sistema-de-control-de-un-motor-en-Arduino

Proyecto desarrollado en Tinkercad para controlar la dirección de movimiento de un vehículo mediante cuatro motores DC y botones de control. La simulación emplea un Arduino Uno, cuatro motores DC, un puente H, 4 botones, una protoboard y cables de conexión virtuales. El sistema permite modificar el sentido de giro de los motores para simular el desplazamiento del vehículo hacia adelante, hacia atrás y los giros a la izquierda o derecha. Dependiendo de la dirección seleccionada, algunos motores giran en sentido horario y otros en sentido antihorario, reproduciendo el comportamiento necesario para la maniobrabilidad de un vehículo móvil.
