# Sistema-de-control-de-un-motor-en-Arduino

Proyecto desarrollado en Tinkercad para controlar la velocidad de un motor DC mediante un Arduino Uno y un potenciómetro. La simulación emplea un Arduino Uno, un motor DC, un potenciómetro, una protoboard, un MOSFET, un transistor NPN, una resistencia, una batería de 9V y cables de conexión. El Arduino lee la posición del potenciómetro y genera una señal PWM proporcional que regula la potencia suministrada al motor, permitiendo modificar su velocidad de giro.
